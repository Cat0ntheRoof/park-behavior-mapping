# 公园行为分段统计（手绘图 → 标注 → 统计 → 出图）

> **方法出处**：三编码体系（人数-性别-活动）与"按交点分段"的统计口径由 **Hon Sytsi** 提出，用于风景园林专业的建成环境行为观察。本 Skill 只负责执行流程，不改变方法本身。

## 先判断可行性

**没有任何现成 OCR 能可靠读这类手写数字**。实测（字高 12×20 px、被箭头压着）：

| 模型 | `2-3-1` 读成 |
|---|---|
| TrOCR 手写版 | `girls . I` |
| EasyOCR（限字符） | `4 \| 4 \| 72 \| 3` |
| PP-OCRv4 | `2-3-1` ✅（但换被切断的框就退化成 `J-2J`） |

所以流程必须是 **机器初读 + 人眼确认**。任何声称能全自动的方案都不成立。

## 流程

### 1. 打包标注网页

```bash
python python/build_tool.py --images <扫描图…> --labels <名称…> --out <输出.html>
```
产出单文件 HTML（图片 base64 内嵌），浏览器打开即可，离线可用。

### 2. 用户在网页里标注

- `S` 画路段：点起点 → 点终点，沿笔迹自动寻路；
- `N` 拉框，拖顶部圆点旋转；
- `D` 选区检测补框；
- 点路段 → 点框 →「挂到选中路段」强制归属；
- `R` 读数：人数 / 性别 / 活动 三个输入框；
- 导出 JSON。

### 3. 机器初读

```bash
python python/ocr_read.py --export <标注结果.json> --images i1=<图1> --out work/
```
产出 `suggestions.json`，回网页「导入建议值」逐条确认。

### 4. 出图

```bash
python python/render_figure.py --export <json> --key i1 --image <图> --out 图1.png --csv 统计.csv
```

## 编码约定

`人数-性别-活动`

- 人数 1–2 位；
- 性别 1=男 2=女 3=男女均衡；
- 活动 1–13（步行/跑步/骑行/坐憩/社交/亲子/锻炼/遛狗/野餐/手机/拍照/文化/其他）。

停留由活动推导：1–3→路过，8/11→短暂<5min，其余→≥5min。

## 必须检查的坑

1. **角度方向**：导出角度是 `[0,180)`，`>90°` 直接旋转会让文字上下颠倒 → 识别率腰斩。裁剪前 `ang%180; if ang>90: ang-=180`。
2. **人数是两位数**：校验正则写 `^\d-` 会让 `10-2-6` 存不进去。
3. **性别 3 是合法的**（均衡），不是笔误；但 4 以上要报错，不能静默接受。
4. **并框/碎框**：用墨迹投影的字符段数判断，4–7 段是单码，≥8 段要再切，≤3 段多为碎片。
5. **未挂路段的框**：必须单独列出来，不能悄悄不进统计。

## 质量基准

典型量级：40–100 个注记框、20 条上下路段时，模型给出 40% 左右的建议，其余人工补。
一次完整流程（标注 + 读数）约 1–2 小时，纯手工转录通常需要 2–3 天。

**预期就是 40–45% 自动 + 人工补齐**，不要承诺更高。
